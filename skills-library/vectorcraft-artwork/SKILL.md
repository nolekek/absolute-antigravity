# VectorCraft: Scalable Vector Artwork

Use VectorCraft for designing vector illustrations, crisp brand marks, complex Bezier path operations, typographic layouts, and production-ready SVG assets.

## Engine & Protocol
- **MCP Server**: `artcraft-vectorcraft` (`vectorcraft-cli mcp --headless`)
- **CLI Fallback**: `vectorcraft-cli mcp`
- **Supported Formats**: `.vcraft`, `.svg`, `.ai`, `.pdf`, `.eps`

## Vector Techniques
1. **Bezier Curves & Boolean Ops**:
   - Construct paths using exact math; perform union, subtract, intersect, and exclude operations.
2. **Style Attributes**:
   - Manage gradients, stroke caps, dash arrays, and vector clipping masks.
3. **Direct React/Web Integration**:
   - Export optimized, clean SVGs for direct consumption in Tailwind and React components.
