# PhotoCraft: Raster Graphics Studio

Use PhotoCraft for high-resolution raster graphic creation, layer manipulation, photo retouching, alpha masking, blending modes, adjustment layers, and batch format conversion.

## Engine & Protocol
- **MCP Server**: `artcraft-photocraft` (`photocraft-cli mcp`)
- **CLI Fallback**: `photocraft-cli convert`, `photocraft-cli info`, `photocraft-cli run`
- **Supported Formats**: `.pcraft`, `.psd`, `.png`, `.jpg`, `.webp`, `.exr`, `.tif`

## Studio Workflows
1. **Layer Tree Analysis**:
   - Inspect document hierarchy, layer bounds, opacity, and blend modes.
2. **Non-Destructive Adjustments**:
   - Apply curves, levels, HSL shifts, and smart filters via command pipeline.
3. **Batch Asset Generation**:
   - Automate web asset generation, responsive resizing, and modern image compression.
