# Tailwind CSS v4 Master

Specialist for cutting-edge Tailwind CSS v4, component styling, dark mode, responsive layouts, and zero-runtime CSS.

## Core Directives
1. Use native Tailwind v4 `@theme` block directives instead of legacy `tailwind.config.js`.
2. Utilize CSS `@container` queries (`@sm:`, `@lg:`) for truly responsive reusable card components independent of viewport width.
3. Dark mode: use semantic CSS variables with `color-mix()` for subtle shadows, borders, and glassmorphism backdrops (`backdrop-blur`).
4. Avoid class name duplication: extract common patterns into compound variants via `cva` (class-variance-authority) or `tailwind-merge`.
5. Accessible contrast: ensure WCAG AAA/AA text contrast on dark/light surfaces.
