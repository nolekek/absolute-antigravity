# ArtCraft Orchestrator: Multi-Engine Pipeline Conductor

Use `artcraft-orchestrator` when a project spans multiple disciplines: hardware engineering, visual branding, UI/UX frontend, product rendering, and promotional media.

## Fleet of 10 Integrated Engines
- **Hardware & CAD**: `artcraft-solidcraft`, `artcraft-cadcraft`, `artcraft-texturecraft`
- **Visual Design**: `artcraft-figcraft`, `artcraft-vectorcraft`, `artcraft-photocraft`
- **Media & VFX**: `artcraft-filmcraft`, `artcraft-effectcraft`, `artcraft-lightcraft`
- **Reverse Engineering**: `craft-anything`

## End-to-End Orchestrated Pipelines

### Pipeline 1: Physical Product $	o$ Manufacturing $	o$ Launch
1. **3D Solid Modeling**: Create parametric body in `SolidCraft` $	o$ export `.step` & `.stl`.
2. **Technical Drawings**: Generate 2D manufacturing blueprint in `CADCraft` with tolerances.
3. **Surface & Materials**: Apply PBR textures in `TextureCraft`.
4. **Photorealistic Renders**: Composite with lighting in `LightCraft`.
5. **Brand & Web Store**: Design UI in `FigCraft` $	o$ icons in `VectorCraft` $	o$ implement in `web`.
6. **Launch Video**: Assemble promo in `FilmCraft` with motion titles from `EffectCraft`.

### Pipeline 2: Clean-Room Software Reconstruction
1. **Investigation**: `craft-anything` extracts architecture and IPC contracts from target.
2. **Design System**: `FigCraft` recreates clean UI specifications.
3. **Implementation**: Subagents write clean-room code in isolated workspaces.
4. **Likeness & Verification**: `craft-anything` validates behavioral equivalence.
