# FL.ru DOM Selectors & Structure Reference for Chrome DevTools MCP

Этот документ содержит технические детали структуры страниц fl.ru для надежного взаимодействия через инструменты `chrome-devtools-mcp` (`take_snapshot`, `fill`, `click`, `upload_file`, `evaluate_script`).

---

## 1. Ключевые URL-эндпоинты FL.ru

| Страница | URL | Описание |
|---|---|---|
| Все проекты | `https://www.fl.ru/projects/` | Главная лента всех заказов |
| Открытые заказы | `https://www.fl.ru/projects/?kind=5` | Только проекты, открытые для откликов |
| Проекты с безопасной сделкой | `https://www.fl.ru/projects/?bs=1` | Только заказы с резервированием средств |
| Программирование / IT | `https://www.fl.ru/projects/category/programmirovanie/` | Специфический раздел разработки ПО |
| Карточка заказа | `https://www.fl.ru/projects/<id>/<slug>.html` | Страница конкретного проекта с формой отклика |
| Чат / Диалоги | `https://www.fl.ru/messages/` | Личные сообщения и диалоги с заказчиками |
| Мои отклики | `https://www.fl.ru/projects/my-offers/` | Список проектов, где оставлены заявки |

## 2. Структура ленты проектов (`/projects/`)

При вызове `take_snapshot` элементы карточки проекта в дереве доступности обычно представлены следующими маркерами:

- **Контейнер проекта**: элементы с селектором `.b-post` или `[id^="project-item-"]`
- **Заголовок и ссылка**: `a.b-post__link` или ссылки внутри `h2`/`h3`. URL формата `/projects/<id>/...`
- **Бюджет**: элементы с текстом цены (например, `10 000 ₽`, `По договоренности`, `Бюджет: ...`)
- **Бейджи**:
  - `PRO` - заказ доступен только пользователям с аккаунтом PRO.
  - `Безопасная сделка` / `БС` - заказ гарантирован оплатой через сервис.
  - `Срочно` - повышенный приоритет.
- **Счетчик ответов**: текстовый блок `Ответов: X` или `X откликов`.

### Пример извлечения через `evaluate_script`:
```javascript
() => {
  const items = Array.from(document.querySelectorAll('.b-post, [data-project-id]'));
  return items.map(el => {
    const titleLink = el.querySelector('a[href*="/projects/"]');
    const priceEl = el.querySelector('.b-post__price, [class*="price"]');
    const textEl = el.querySelector('.b-post__txt, [class*="description"]');
    const isPro = !!el.querySelector('[class*="pro-only"], .b-badge_pro');
    return {
      title: titleLink?.innerText?.trim(),
      url: titleLink?.href,
      price: priceEl?.innerText?.trim(),
      snippet: textEl?.innerText?.trim(),
      isPro
    };
  }).filter(p => p.title && p.url);
}
```

## 3. Форма отклика на странице проекта

На странице проекта форма отклика активируется блоком «Ответить на проект» или отображается в нижней части описания:

- **Кнопка вызова формы** (если скрыта): кнопка с текстом `Ответить на проект` / `Оставить заявку`.
- **Поле текста отклика**: `<textarea id="descr" ...>` или блок с атрибутом `contenteditable` / `textarea` внутри формы отклика.
- **Стоимость (бюджет)**: `<input name="cost" ...>` или числовое поле для ввода суммы в рублях.
- **Срок выполнения**: `<input name="time" ...>` (в днях или часах).
- **Переключатель «Безопасная сделка»**: флажок или радиокнопка (рекомендуется оставлять включенной при наличии).
- **Прикрепление файлов**: `<input type="file" ...>` (используется с `upload_file`).
- **Кнопка подтверждения**: кнопка «Отправить заявку» или «Ответить».

## 4. Личные сообщения и диалоги (`/messages/`)

- Список контактов: левая колонка диалогов. Непрочитанные сообщения подсвечиваются маркером или бейджем счетчика.
- Окно активного чата:
  - Список входящих сообщений заказчика.
  - Поле ввода сообщения: `textarea` или `div[contenteditable="true"]`.
  - Кнопка скрепки (прикрепление файлов): `<input type="file">`.
  - Кнопка отправки: `button` с иконкой стрелки или текст «Отправить».
