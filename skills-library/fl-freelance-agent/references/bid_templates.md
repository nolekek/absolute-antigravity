# High-Conversion Freelance Proposal (Bid) Playbook

Руководство по составлению откликов на FL.ru, гарантирующих максимальную конверсию в ответ заказчика и безопасную сделку.

---

## 🚫 Анти-паттерны (Чего делать НЕЛЬЗЯ):
1. **Копипаст-портянки**: «Здравствуйте! Меня зовут Иван, опыт 10 лет, знаю 20 языков, делал 500 сайтов...» — заказчик закрывает такой отклик на 2-й секунде.
2. **Пустые обещания без деталей**: «Сделаю быстро и дешево, напишите в телеграм».
3. **Демпинг в 10 раз ниже рынка**: вызывает подозрение в мошенничестве или некомпетентности.
4. **Увод с площадки в первой строке**: может привести к бану аккаунта модерацией FL.ru.

---

## ⭐ Формула идеального отклика (4 Блока):

```
[Блок 1: Понимание сути задачи + готовая техническая связка]
[Блок 2: Архитектура реализации или микро-демо]
[Блок 3: Сроки, бюджет и готовность начать немедленно]
[Блок 4: Ровно 1 профессиональный уточняющий вопрос]
```

---

## 📋 Шаблоны по категориям задач

### 1. Парсинг данных и веб-скрейпинг
```text
Здравствуйте! Изучил задачу по сбору данных с {domain/площадка}.

Готов реализовать парсер на Python (httpx + BeautifulSoup/Playwright):
- Настрою автоматическую пагинацию, сбор всех полей ({список полей из ТЗ}) и валидацию данных.
- Предусмотрю защиту от блокировок: ротацию User-Agent, корректные задержки и обработку таймаутов сети.
- Выгрузка данных в структурированный Excel (XLSX) или CSV по вашей структуре.

Срок: {X} часа(ов) с момента старта.
Стоимость: {X} руб.

Уточните, пожалуйста: требуется ли разовый сбор или скрипт должен работать по расписанию (cron/планировщик)?
```

### 2. Telegram-боты и автоматизация
```text
Добрый день! Ознакомился с ТЗ на Telegram-бота для {назначение бота}.

Предлагаю следующее решение:
- Стек: Python + aiogram 3.x (асинхронный, быстрый фреймворк).
- База данных: SQLite / PostgreSQL для сохранения пользователей и истории запросов.
- Удобная клавиатура (Inline/Reply) с пошаговыми сценариями (FSM).
- Логирование действий и админ-панель для рассылок и статистики.

Могу упаковать в Docker для запуска в 1 команду на вашем сервере или помочь с развертыванием.
Срок выполнения: {X} дня / часов.
Бюджет: {X} руб.

Подскажите: планируется ли интеграция с внешними платежными системами или API сторонних сервисов?
```

### 3. Верстка и Frontend (React, Vue, HTML/CSS)
```text
Здравствуйте! Готов аккуратно и адаптивно сверстать {лендинг/компонент/страницу}.

Что будет сделано:
- Чистый, семантичный код без лишних тяжелых библиотек (Mobile First).
- Полная адаптивность под все экраны: смартфоны, планшеты, десктопы (Retina ready).
- Плавные микро-анимации интерактивных элементов.
- 100/100 по Google PageSpeed (оптимизация шрифтов, SVG, сжатие изображений).

Срок: {X} часа(ов).
Стоимость: {X} руб.

Макет в Figma уже полностью готов со всеми адаптивными разрешениями?
```

### 4. Исправление багов и скрипты
```text
Здравствуйте! Готов оперативно локализовать и устранить ошибку в {название технологии/системы}.

План действий:
1. Воспроизведу ошибку в изолированном окружении, проверю логи стектрейса.
2. Устраню первопричину багов без сайд-эффектов для смежного функционала.
3. Напишу тест, подтверждающий корректность работы после фикса.

Готов подключиться прямо сейчас.
Срок: до {X} часов.
Стоимость: {X} руб.
```
