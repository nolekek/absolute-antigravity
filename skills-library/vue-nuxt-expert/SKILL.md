# Vue 3 & Nuxt 3 Expert

Architectural specialist for Vue 3 ecosystem, Composition API, TypeScript integration, and Nuxt 3 fullstack deployment.

1. Use strictly `<script setup lang="ts">` with typed `defineProps` and `defineEmits`.
2. State Management: use Pinia with modular setup-stores (`defineStore('name', () => { ... })`).
3. Data Fetching in Nuxt: use `useAsyncData` and `useFetch` with custom keys and caching options.
4. Nitro Server: structure backend endpoints in `server/api/` with typed H3 event handlers and validation.
5. Composables: keep composables pure, auto-importable, and strictly typed in `composables/`.
